# ROS_robot_omni
Dự án ROS 2 Jazzy &amp; Gazebo Harmonic: Hệ thống mô phỏng robot đa hướng (Mecanum) tự hành trong bệnh viện. Tích hợp Nav2 (AMCL, Lidar, Camera 3D) để điều hướng, kết hợp bộ lọc nhiễu EKF. Nổi bật với Behavior Tree (C++) tùy chỉnh thoát kẹt thông minh, thuật toán di truyền (GA) tối ưu quỹ đạo và phần mềm Python GUI quản lý trạm.
