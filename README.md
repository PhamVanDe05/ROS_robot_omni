This project provides a comprehensive simulation system for an omni-directional (Mecanum) autonomous mobile robot operating within a hospital environment. It fully integrates the **ROS 2 Jazzy**, **Gazebo Harmonic**, and **Nav2** ecosystems to perform mapping, localization, and autonomous navigation tasks, accompanied by an intuitive mission control GUI.

## ✨ Key Features

* 🔄 **Omni-Directional Movement:** Utilizes the `mecanum_drive_controller` to control 4 independent wheels, allowing the robot to move laterally, diagonally, and smoothly in narrow hospital spaces.
* 🏥 **Realistic Hospital Environment:** Detailed simulation using the `hospital_full.world`, including complex obstacles such as hospital beds, narrow corridors, and dynamic objects.
* 📡 **Nav2 & Advanced Sensors:** 
  * Implements the **AMCL** algorithm for highly accurate localization. 
  * Costmaps are generated by fusing data from **Lidar** (`/scan_front`, `/scan_rear`) and an **RGBD Camera** (converting Depth images into `PointCloud2`).
* 🧠 **Smart Navigation:** 
  * Integrates a `velocity_smoother` for safe and smooth acceleration/deceleration.
  * Custom **C++ Behavior Tree** (`smart_recovery_bt.xml` & `is_space_clear_plugin`) allows the robot to analyze its surroundings and automatically calculate intelligent escape angles when stuck.
* 🖥️ **Fleet Control Interface (GUI):** A custom Python/Tkinter application (`mission_control.py`) featuring a **Genetic Algorithm (GA)** to automatically calculate and optimize the shortest route (TSP) across multiple waypoints.
* 🧹 **Data Optimization:** Implements `laser_filters` to clean up sensor noise before feeding data into the Nav2 stack.

---

## 🛠️ Core Technologies Implemented

* **Data Synchronization:** Configured `bridge_config.yaml` to seamlessly bridge Lidar, 3D Camera, and IMU data between Gazebo and ROS 2.
* **Costmap & DWB Local Planner Tuning:** Fine-tuned `global_costmap` and `local_costmap` to process 3D point clouds efficiently and eliminate obstacle "ghosting". Optimized acceleration and velocity matrices for agile yet safe movement without dropping frames.
* **Custom Behavior Tree (C++):** Developed a custom C++ plugin capable of reading the scan map and dynamically calculating rotation angles to bypass dynamic obstacles, overcoming the limitations of standard recovery behaviors.

## 🚀 Installation Guide 

**1. Clone the repository into your workspace:**
```bash
cd ~/ros2_ws/src
git clone <your-github-link-here>
2. Install dependencies using rosdep:

Bash
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -r -y
3. Build the project:

Bash
colcon build --packages-select robot_omni --symlink-install
source install/setup.bash
📖 User Guide
To operate the system, you need to open 3 separate Terminals and run the following steps in sequence:

Step 1: Launch the Simulation Environment (Gazebo)
Open Terminal 1 and run the following command to load the 3D hospital, spawn the Mecanum robot, and activate the motor controllers along with the EKF noise filter:

Bash
ros2 launch robot_omni gazebo_control.launch.py
Step 2: Launch the Navigation System (Nav2) & RViz
Open Terminal 2 and start the localization system:

Bash
ros2 launch robot_omni localization.launch.py
RViz will open with the 2D map (hospital_map). The AMCL system will automatically initialize the starting pose, and sensor data (Lidar and green PointCloud clusters from the 3D Camera) will visualize the scanned surroundings.

Step 3: Launch the Mission Control GUI
Open Terminal 3 and execute the Python script:

Bash
python3 src/robot_omni/scripts/mission_control.py
The AMR Fleet Management System GUI will appear, automatically loading a default list of waypoints (e.g., P16 -> P7 -> P12) into the mission queue.

Step 4: Schedule & Optimize Route (Genetic Algorithm)
In the "AVAILABLE WAYPOINTS" panel, you can select additional destinations and click "Add Selected [+]".

Once your desired stations are in the "MISSION QUEUE", click the green "⚙️ OPTIMIZE ROUTE (GA)" button.

The system will run the Genetic Algorithm (GA) combined with the A* Costmap to calculate the shortest path, drawing the optimized red trajectory directly on the GUI's 2D map.

Step 5: Execute Mission & Handle Obstacles
Click the blue "🚀 EXECUTE MISSION" button to start the robot. You can watch it navigate through the corridors in RViz.

If dynamic obstacles block the path, the Custom C++ Behavior Tree will automatically trigger Recovery behaviors (backing up, rotating to find a clear angle) to bypass them.

Click the red "🛑 EMERGENCY STOP" button at any time to immediately halt the robot; pending waypoints will remain saved in the queue to resume later.
